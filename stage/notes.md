## Flownook 1.7.6 (pre-release)

> **Pre-release: test build, install over 1.7.5.** Auto-update keeps offering 1.7.5 until this build is promoted.

- **Desktop pet, ultra edition.** No more cut-off or fragment-looking pet at the top edge or on dark wallpapers (window stays on the pet's monitor, padded sprite, light outline). 172 behaviours: rides, dances, its own tiny PC and bed, bug hunt, visitors, moods, talk lines and focus nags, toy menu, optional sounds, cursor play and desktop tidy (off by default). All settings in Settings ▸ Pet.
- **Markdown table fix.** Body rows no longer shift a column right, no pink cell boxes or stray scrollbar, and tables export properly to HTML / PDF / Word.
- **New Markdown viewer.** Open any `.md` file in a standalone viewer (rendered like notes, Ctrl+E to edit, Ctrl+S saves back keeping encoding and line endings, Find, zoom, "Open in Flownook"). Adds "Open with Flownook" without taking over your existing default app.

**Known issues**
- Windows-only pet features (desktop icon positions, cursor play, tidy) are new and lightly tested.
